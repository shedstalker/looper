# REVIEW

Write your real answer in EXCHANGE/REVIEW.next.md (without the marker line), then publish.
Only the Handoff line is required. For a review, add the Verdict line; for research, access
or other requests a plain answer is fine. Everything else is free-form and proportionate.

Handoff: <number> <id>   (copy from `status`)
Verdict: PASS | REPAIR | BLOCKED   (reviews; optional otherwise)
Checked: what you actually inspected
Findings / answer: the important points, with file/line, sources or evidence
Next action: what the worker should do now
